## 목적

다음 대화·작업을 이어가기 위해 **`docs/AGENT_HANDOFF.md`** 내용을 **실제로 읽고** 현재 질문에 필요한 맥락으로 요약·인용합니다.

## 절차

1. **`docs/AGENT_HANDOFF.md`** 파일을 Read 도구로 전체 읽습니다. (경로가 다르면 저장소 루트에서 `AGENT_HANDOFF.md` 또는 `docs/` 아래를 검색합니다.)
2. 사용자 메시지와 관련 있는 섹션만 골라 **짧게 요약**합니다. 표·플로우·경로는 그대로 옮기지 말고 필요한 줄만 인용합니다.
3. 문서에 없는 내용은 추측하지 말고, 필요하면 **`AGENTS.md`** 또는 코드를 추가로 읽는다고 안내합니다.

## 출력

- 사용자가 “요약만”을 원하면 5~10줄 이내 **불릿 요약**.
- 구체적 수정 요청이 있으면 핸드오프 + 해당 스크립트 경로를 **코드 인용 형식**으로 짚어 줍니다.

## 제약

- 핸드오프 파일을 이 커맨드만으로 **수정하지 않습니다.** 갱신이 필요하면 **`/handoff-write`** 를 안내하세요.
- 응답은 프로젝트 규칙에 따라 **한국어**로 작성합니다.
